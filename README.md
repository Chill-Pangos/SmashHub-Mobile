# SmashHub Mobile - React Native Expo App

Ứng dụng di động hỗ trợ và quản lý giải đấu bóng bàn.

## 📱 Tech Stack

- **React Native Expo** - SDK 54
- **TypeScript** - Type safety
- **Yarn 4.10.3** - Package manager (node-modules mode)
- **NativeWind v4** - Tailwind CSS for React Native
- **React Navigation 7.x** - Navigation (Stack + Bottom Tabs)
- **Lucide React Native** - Icon library
- **AsyncStorage** - Local storage
- **Axios** - HTTP client
- **React Native Reanimated 3.17.x** - Animations
